# Chi tiêu

App quản lý chi tiêu cá nhân (Next.js + IndexedDB/Dexie). Dữ liệu lưu cục bộ trên máy.

```bash
npm install
npm run dev   # http://localhost:3100
```

## Dùng trên điện thoại (cùng Wi-Fi)

```bash
npm run build && npm start
```

Mở **http://nams-macbook-pro.local:3100** trên điện thoại, rồi chọn "Thêm vào màn hình chính".
